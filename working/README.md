# Working Documents

This directory contains non-authoritative project memory for active or
historical engineering work. It must not override current implementation,
tests, repository instructions, or durable documentation.

- `audits/` contains point-in-time audit scope and reports.
- `plans/` contains temporary implementation plans.
- `notes/` contains investigation notes.
- `archive/` retains completed material only when its historical context remains
  useful.

When work ends, delete the document, archive it, or promote confirmed current
behavior into durable documentation.
